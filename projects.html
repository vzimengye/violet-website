End-to-End News Recommendation System

scikit-learn · FastAPI · MLflow · FAISS

Sep 2026 to Present

Turns Microsoft's MIND impression logs into labeled click data, then goes from popularity retrieval to a logistic regression ranker with NDCG/MRR evaluation and MLflow tracking. It's served through FastAPI with request logging and PSI drift checks. Next up is item-based CF, FAISS embedding search, and a LightGBM ranker.

PackSmart

Node.js · JavaScript · REST APIs · OpenAI API · Hugging Face

Mar 2026 to Present

A travel outfit planner that picks daily outfits from your own closet based on trip activities and the weather, using rule-based scoring plus OpenAI API calls. I'm now building a distillation pipeline that generates synthetic closet and trip scenarios, labels them with a large teacher model under a strict JSON schema, and filters them with validators, so a smaller model can replace the API calls.
